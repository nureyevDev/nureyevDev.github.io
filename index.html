Minha API em Python

Esta seção consome uma API própria feita com Flask/FastAPI, hospedada gratuitamente (Render, Railway ou PythonAnywhere). Basta configurar a URL no JavaScript.

Clique para chamar o endpoint /api/status da minha API Python:

from flask import Flask, jsonify
from flask_cors import CORS

app = Flask(__name__)
CORS(app)

# Rota consumida pelo site em produção
@app.route("/api/status")
def status():
    return jsonify({
        "status": "online",
        "linguagem": "Python 3",
        "framework": "Flask",
    })

if __name__ == "__main__":
    app.run()
